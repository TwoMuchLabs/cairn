# Code of conduct

Cairn follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique code and ideas rather than people, and remember that security work involves real people's mistakes. No harassment, discrimination or personal attacks.

Report unacceptable behaviour privately to the maintainers through GitHub (Security → Report a vulnerability is monitored if you need a private channel). Reports are handled confidentially.
